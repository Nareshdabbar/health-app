# Doctor App

Digital therapeutics and metabolic healthcare mobile application built with React Native, Expo Router, and Firebase.

## Features

- CGM / Glucose Monitoring
- Glycemic Charts & TIR
- Diabetes Reversal Programs
- Daily Habit Tracking
- Clinical Care Hub
- Doctor Messaging
- Tele-Consultation
- Metabolic Marketplace
- Cart Management
- Firebase Authentication
- Firestore Data Sync
- Light & Dark Theme

## Tech Stack

- React Native
- Expo
- Expo Router
- TypeScript
- TanStack React Query
- React Context API
- Firebase Auth
- Firebase Firestore
